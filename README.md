# Leann Saligan – Personal Portfolio Website
A personal portfolio website showcasing Leann Saligan’s background, skills, leadership experience, and achievements. It features an introduction, an About Me section with a photo carousel, a skills section highlighting academic writing, Microsoft Office proficiency, and leadership abilities, and a contact section for visitors to get in touch.

Built using HTML, CSS, and JavaScript, the website provides a simple, clean, and responsive way to present personal information and professional qualifications.
